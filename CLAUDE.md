# software-carpentier

- Pull requests: never write the description by hand. Run `node scripts/pr-body.mjs --what "<what and why>" > body.md`, then `gh pr create --body-file body.md`.
- The npm manifest lives in `app/`; the dependency scan and Dependabot are pointed there (kit default is the repo root). Run `node ../scripts/dep-vet.mjs <name>` from `app/` to vet a package.
- Definition of done, CI budget: every GitHub Actions job has `timeout-minutes` (about 2x its worst run, 10 or less unless `# timeout-ok: why`); a workflow or test-suite change puts PR wall-clock and runner minutes before and after in the PR. Enforcer: `scripts/ci-timeouts.mjs` (`.github/workflows/ci-timeouts.yml`); the budget itself is advisory.
- PR review: `.github/workflows/claude-review.yml` reviews each PR when it is opened or marked ready and picks the model from the diff with `scripts/review-model.mjs` (Opus for risky paths such as workflows, dependency files, or over 600 lines / 25 files; Sonnet otherwise; never Haiku; labels `review:deep` / `review:standard` override). It bills the Claude subscription through the `CLAUDE_CODE_OAUTH_TOKEN` repository secret (`claude setup-token` in your own terminal, then `gh secret set CLAUDE_CODE_OAUTH_TOKEN --repo jacgit18/software-carpentier-portfolio`), is never a required check, and says "did not run" on the PR when the token is missing. Rule: `/home/jac/.claude/rules/pr-review-bot.md`.
